# OOPLab11: Design Patterns and the Mini-Project

## Objectives
- Singleton, Factory, Strategy, Observer
- SOLID-style thinking: single responsibility, open for extension
- Integrate everything in one application (Library Management System)

## How to run in IntelliJ IDEA
1. **File > Open** and choose this `OOPLab11` folder (if asked for a Project SDK, pick any JDK 17 or newer).
2. Open a class listed below and click the green arrow next to its `main` method.
   Files are read/written relative to the project root (the default working directory).

## Key conclusion for the lab record
Design patterns are named solutions to recurring problems. The mini-project combines abstract class + interface, polymorphism, custom exceptions, Maps, streams and CSV persistence. See docs/REPORT.md and docs/ClassDiagram.md.
